# WorthMeaning

Local Worth Report tool for [worthmeaning.com](https://worthmeaning.com).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What it does

Paste a URL → Worth Report with:

- Estimated worth range
- Estimated visits / revenue
- Confidence + exit readiness
- Plain-English **meaning** of the number
- Signals and next steps

Estimates are heuristic (public HTML + domain signals), not formal appraisals.
